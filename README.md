# statistics-data-analysis
Сборник работ по статистике и анализу данных: проверка гипотез, регрессионный анализ, работа с выбросами и визуализация

## Содержание

### [Домашняя работа 1: Основы статистики и анализ данных](Oganov_Alexey_MIVT_24_3_1_homework_1.ipynb)
- **Анализ интервальных рядов** - гистограмма, расчет среднего, моды, медианы (встроенные методы и собственные реализации)
- **Работа с распределениями** - генерация выборки из N(5,2), построение PDF/CDF, расчет 95% доверительного интервала
- **Корреляционный анализ** - диаграммы рассеяния, вычисление ковариации и корреляции для данных datasaurus
- **Проверка гипотез** - тестирование H₀: μ=25 против Hₐ: μ≠25 для выборки размера 50
- **Линейная регрессия** - построение модели для данных angled_blob, расчет R² и интерпретация результатов

### [Домашняя работа 2: Проверка статистических гипотез](Oganov_Alexey_MIVT_24_3_1_homework_2.ipynb)
- **Одновыборочный t-тест** - проверка гипотезы о среднем значении
- **Критерий серий** - проверка случайности выборки
- **Критерий согласия Пирсона** - проверка честности игрального кубика
- **Двухвыборочный t-тест** - сравнение средних двух выборок
- **Проверка распределения** для нечестного кубика

### [Домашняя работа 3: Регрессионный анализ и обработка данных](Oganov_Alexey_MIVT_24_3_1_homework_3.ipynb)
- **Линейная регрессия** - предсказание вкладов на основе зарплат
- **Метрики качества**: MSE, MAE, R²
- **Обнаружение выбросов** по правилу 3 сигм
- **Метод RANSAC** - робастная регрессия с выбросами
- **Сравнение моделей** с выбросами и без

### [Домашняя работа 4: Прикладной статистический анализ](Oganov_Alexey_MIVT_24_3_1_homework_4.ipynb)
- **Интервальные ряды** - анализ распределения IQ по формуле Старджесса
- **Проверка гипотез** о среднем для зарплат разработчиков
- **Линейная регрессия** с метриками качества (MSE, MAE, R²)
- **Борьба с выбросами** в данных о пассажирах авиалиний
- **Ядерные оценки плотности (KDE)** - анализ распределения IQ
- **Гамма-функция** - реализация и визуализация

## Используемые технологии

- **Python** + Jupyter Notebook
- **Pandas, NumPy** - обработка данных
- **Matplotlib, Seaborn** - визуализация
- **SciPy, Statsmodels** - статистический анализ
- **Scikit-learn** - машинное обучение и метрики

## Приобретенные навыки

- **Статистические тесты**: t-тесты, критерий Пирсона, критерий серий
- **Регрессионный анализ**: линейная регрессия, оценка качества моделей
- **Работа с выбросами**: правило 3 сигм, метод RANSAC
- **Визуализация данных**: гистограммы, scatter plots, KDE, PDF/CDF
- **Проверка гипотез**: формулировка и тестирование статистических гипотез
- **Анализ распределений**: нормальное распределение, гамма-функция
- **Корреляционный анализ**: ковариация, корреляция, диаграммы рассеяния
